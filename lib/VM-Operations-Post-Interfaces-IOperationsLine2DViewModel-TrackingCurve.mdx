## TrackingCurve {#VM_Operations_Post_Interfaces_IOperationsLine2DViewModel_TrackingCurve}

Gets or sets whether data tracking is enabled for the 2D chart. `true` enables tracking and `false` disables it.

```csharp
bool TrackingCurve { get; set; }
```

### Property Value

 bool

### Remarks

Changing this value updates the chart tracking control. [`TrackingOption`](/lib/VM-Operations-Post-Interfaces-IOperationsLine2DViewModel-TrackingOption) determines whether tracking displays one or multiple curves.
