## IsFollowingRotXAxis {#VM_Operations_Post_Interfaces_IOperationsAnimation_IsFollowingRotXAxis}

Gets or sets whether camera tracking follows target rotation around the X axis when `TransformationType` is `Rotation`.

```csharp
bool IsFollowingRotXAxis { get; set; }
```

### Property Value

 bool

### Remarks

This flag is used when [`TransformationType`](/lib/VM-Operations-Post-Interfaces-IOperationsAnimation-TransformationType) is `Rotation`. It selects whether target rotation around the X axis changes the following camera.
When this value is `false`, target rotation around the X axis is not applied to camera tracking.
