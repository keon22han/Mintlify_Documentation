## Order {#VM_Operations_Post_Interfaces_IOperationsSignalProcessingLineDataSeriesViewModel_Order}

Gets or sets the filter order passed to the filtering calculation.


### Property Value

### Remarks

This value applies when [`SignalProcessingType`](/lib/VM-Operations-Post-Interfaces-IOperationsSignalProcessingLineDataSeriesViewModel-SignalProcessingType) selects filtering. Changing it recalculates the calculated curve when an original curve exists.
