## PolynomialOrder {#VM_Operations_Post_Interfaces_IOperationsSignalProcessingLineDataSeriesViewModel_PolynomialOrder}

Gets or sets the polynomial order passed to Savitzky-Golay smoothing.

```csharp
int PolynomialOrder { get; set; }
```

### Property Value

 int

### Remarks

This value applies only when [`SmoothingType`](/lib/VM-Operations-Post-Interfaces-IOperationsSignalProcessingLineDataSeriesViewModel-SmoothingType) selects Savitzky-Golay smoothing. The calculation returns no curve when the window is too small for the selected order.
