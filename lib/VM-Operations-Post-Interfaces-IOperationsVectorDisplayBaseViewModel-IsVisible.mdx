## IsVisible {#VM_Operations_Post_Interfaces_IOperationsVectorDisplayBaseViewModel_IsVisible}

Gets or sets whether the vector display is visible. `true` shows it and `false` hides it.

```csharp
bool IsVisible { get; set; }
```

### Property Value

 bool

### Remarks

Changing this value changes whether the vector and its label are rendered.
