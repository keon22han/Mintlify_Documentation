## CylindricalAxisR {#VM_Operations_Post_Interfaces_IOperationsCSYSViewModel_CylindricalAxisR}

Gets or sets the radial axis selected from [`CoordinateType`](/lib/VM-Models-Post-CoordinateType) for cylindrical coordinates.

```csharp
CoordinateType CylindricalAxisR { get; set; }
```

### Property Value

 [CoordinateType](/lib/VM-Models-Post-CoordinateType)

### Remarks

This property applies when [`CurrentCoordinateSystemType`](/lib/VM-Operations-Post-Interfaces-IOperationsCSYSViewModel-CurrentCoordinateSystemType) is cylindrical. The coordinate system keeps the primary and secondary axes distinct.
