## GetDocument\(string\) {#VM_API_Post_Operations_ApplicationHandler_GetDocument_System_String_}

Retrieves an imported document by its file path.

```csharp
public IOperationDocument GetDocument(string filepath)
```

### Parameters

`filepath` string

The path supplied when the `.dfr` result file was imported.

### Returns

 [IOperationDocument](/lib/VM-ViewModels-Post-Interfaces-IOperationDocument)

The matching [`IOperationDocument`](/lib/VM-ViewModels-Post-Interfaces-IOperationDocument), or &lt;code>null&lt;/code> when the path is not imported.

### Examples

```python
# RESULT_FILE_PATH : .dfr result file path
document = application_handler.GetDocument(RESULT_FILE_PATH)
```

### Remarks

The lookup uses the path supplied to [AddDocument\(IList&lt;string\>\)](/lib/VM-API-Post-Operations-ApplicationHandler-AddDocument). A `.dfhpc` path is converted to a `.dfr` path before the lookup.

### Exceptions

 FileLoadException

Thrown when a `.dfhpc` path is supplied and conversion to `.dfr` fails.
