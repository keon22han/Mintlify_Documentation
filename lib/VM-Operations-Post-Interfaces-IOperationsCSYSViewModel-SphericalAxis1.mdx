## SphericalAxis1 {#VM_Operations_Post_Interfaces_IOperationsCSYSViewModel_SphericalAxis1}

Gets or sets the first spherical-axis direction selected from [`CoordinateType`](/lib/VM-Models-Post-CoordinateType) when [`CurrentCoordinateSystemType`](/lib/VM-Operations-Post-Interfaces-IOperationsCSYSViewModel-CurrentCoordinateSystemType) is spherical.

```csharp
CoordinateType SphericalAxis1 { get; set; }
```

### Property Value

 [CoordinateType](/lib/VM-Models-Post-CoordinateType)

### Remarks

The value affects the orientation used to interpret spherical coordinates and applies only to spherical representation.
