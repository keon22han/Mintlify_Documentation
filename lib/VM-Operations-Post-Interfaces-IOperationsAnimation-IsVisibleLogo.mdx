## IsVisibleLogo {#VM_Operations_Post_Interfaces_IOperationsAnimation_IsVisibleLogo}

Gets or sets whether the logo overlay is visible. `true` shows the logo and `false` hides it.

```csharp
bool IsVisibleLogo { get; set; }
```

### Property Value

 bool

### Remarks

The logo is drawn in the animation view and in captured animation frames when this value is `true`. Use [`LogoPath`](/lib/VM-Operations-Post-Interfaces-IOperationsAnimation-LogoPath), [`LogoPosition`](/lib/VM-Operations-Post-Interfaces-IOperationsAnimation-LogoPosition), [`LogoHeight`](/lib/VM-Operations-Post-Interfaces-IOperationsAnimation-LogoHeight), [`LogoWidth`](/lib/VM-Operations-Post-Interfaces-IOperationsAnimation-LogoWidth), and [`Opacity`](/lib/VM-Operations-Post-Interfaces-IOperationsAnimation-Opacity) to configure it.
