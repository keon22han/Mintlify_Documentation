## TransformationOffsetAngle {#VM_Operations_Post_Interfaces_IOperationsCSYSViewModel_TransformationOffsetAngle}

Gets or sets the angular offset applied to the parent reference orientation. The value is interpreted with [`TransformationOffsetRotationType`](/lib/VM-Operations-Post-Interfaces-IOperationsCSYSViewModel-TransformationOffsetRotationType) and [`TransformationOffsetRotationAxis`](/lib/VM-Operations-Post-Interfaces-IOperationsCSYSViewModel-TransformationOffsetRotationAxis).

```csharp
Vector TransformationOffsetAngle { get; set; }
```

### Property Value

 [Vector](/lib/VM-Vector)

### Remarks

Changing this value changes the coordinate-system orientation relative to the parent frame at each animation frame.
