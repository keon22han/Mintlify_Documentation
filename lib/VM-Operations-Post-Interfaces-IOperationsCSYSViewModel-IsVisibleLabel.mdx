## IsVisibleLabel {#VM_Operations_Post_Interfaces_IOperationsCSYSViewModel_IsVisibleLabel}

Gets or sets whether the coordinate-system label is rendered. `true` shows the label and `false` hides it.

```csharp
bool IsVisibleLabel { get; set; }
```

### Property Value

 bool

### Remarks

Label background visibility and label colors affect the rendered label only when this value is `true`.
