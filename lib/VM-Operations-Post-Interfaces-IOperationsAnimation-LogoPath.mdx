## LogoPath {#VM_Operations_Post_Interfaces_IOperationsAnimation_LogoPath}

Gets or sets the logo image file path. (`.bmp`, `.jpg`, `.png`)

```csharp
string LogoPath { get; set; }
```

### Property Value

 string

### Remarks

The path identifies the image drawn when [`IsVisibleLogo`](/lib/VM-Operations-Post-Interfaces-IOperationsAnimation-IsVisibleLogo) is `true`. [`LogoHeight`](/lib/VM-Operations-Post-Interfaces-IOperationsAnimation-LogoHeight) and [`LogoWidth`](/lib/VM-Operations-Post-Interfaces-IOperationsAnimation-LogoWidth) control the displayed size.
