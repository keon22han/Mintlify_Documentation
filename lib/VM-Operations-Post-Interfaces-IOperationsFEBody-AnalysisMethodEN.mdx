## AnalysisMethodEN {#VM_Operations_Post_Interfaces_IOperationsFEBody_AnalysisMethodEN}

```csharp
AnalysisMethodEN AnalysisMethodEN { get; set; }
```

### Property Value

### Remarks

This property applies when [`AnalysisType`](/lib/VM-Operations-Post-Interfaces-IOperationsFEBody-AnalysisType) selects strain-life analysis. Changing it updates the mean-stress method stored for fatigue evaluation.
