## LegendPlacement {#VM_Operations_Post_Interfaces_IOperationsLegendModifier_LegendPlacement}

Gets or sets the legend placement selected from [`LegendPlacementType`](/lib/VM-Models-Post-LegendPlacementType) relative to the chart.

```csharp
LegendPlacementType LegendPlacement { get; set; }
```

### Property Value

 [LegendPlacementType](/lib/VM-Models-Post-LegendPlacementType)

### Remarks

Setting `Inside` shows the legend inside the chart. Setting another placement switches the legend to the outside layout.
