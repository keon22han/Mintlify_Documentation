Identifies the analysis category of a result document, used to select which [`IAnalysisResultViewModel`](/lib/VM-ViewModels-Post-IAnalysisResultViewModel) is retrieved with [`GetAnalysisResultViewModel(AnalysisResultType)`](/lib/VM-ViewModels-Post-Interfaces-IOperationDocument-GetAnalysisResultViewModel).

```csharp
public enum AnalysisResultType
```

## Fields

`Dynamics = 0` 

Description: "Dynamics"

Selects the analysis results calculated by a dynamic, time-domain simulation.



`Eigenvalue = 1` 

Description: "Eigenvalue"

Selects the analysis results calculated by an eigenvalue, frequency-domain analysis.



`Nothing = 7` 

Description: "Nothing"

Indicates that no analysis result is available for the requested category.



`Statics = 4` 

Description: "Statics"

Selects the analysis results calculated by a static simulation.
