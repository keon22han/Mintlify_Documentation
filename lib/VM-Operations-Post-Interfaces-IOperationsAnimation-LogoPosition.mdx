## LogoPosition {#VM_Operations_Post_Interfaces_IOperationsAnimation_LogoPosition}

Gets or sets the logo position selected from [`Layout`](/lib/VM-Models-Post-Layout).

```csharp
Layout LogoPosition { get; set; }
```

### Property Value

 [Layout](/lib/VM-Models-Post-Layout)

### Remarks

[`Layout`](/lib/VM-Models-Post-Layout) selects a predefined corner position for the overlay in the animation view and captured frames when [`IsVisibleLogo`](/lib/VM-Operations-Post-Interfaces-IOperationsAnimation-IsVisibleLogo) is `true`.
