## LogarithmicBase {#VM_Operations_Post_Interfaces_IOperationsCustomAxisViewModel_LogarithmicBase}

Gets or sets the logarithmic base used by a custom axis, such as `2`, `3`, `4`, `5`, `10`, or `E`.

```csharp
string LogarithmicBase { get; set; }
```

### Property Value

 string

### Remarks

This value affects axis labels only when [`AxisType`](/lib/VM-Operations-Post-Interfaces-IOperationsCustomAxisViewModel-AxisType) selects a logarithmic scale.
