## IsVisibleTrajectory {#VM_Operations_Post_Interfaces_IOperationsCSYSViewModel_IsVisibleTrajectory}

Gets or sets whether the coordinate-system trajectory is rendered using [`TrajectoryColor`](/lib/VM-Operations-Post-Interfaces-IOperationsCSYSViewModel-TrajectoryColor). `true` shows it and `false` hides it.

```csharp
bool IsVisibleTrajectory { get; set; }
```

### Property Value

 bool

### Remarks

The trajectory shows the coordinate-system path across animation frames when enabled.
