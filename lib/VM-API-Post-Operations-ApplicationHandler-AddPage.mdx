## AddPage\(string\) {#VM_API_Post_Operations_ApplicationHandler_AddPage_System_String_}

Adds and activates a page with the specified name.

```csharp
public IPage AddPage(string name = null)
```

### Parameters

`name` string

The page name. When omitted, the page receives the default name generated by the Postprocessor.

### Returns

 [IPage](/lib/VM-Operations-Post-Interfaces-IPage)

The newly added [`IPage`](/lib/VM-Operations-Post-Interfaces-IPage).

### Examples

```python
# Add a page to the document.
page_name = "Page"
page = application_handler.AddPage(page_name)
```

### Remarks

Returned `IPage` is active when the method returns. Previously active `IPage` is deactivated.
