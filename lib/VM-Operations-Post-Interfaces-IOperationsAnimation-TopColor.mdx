## TopColor {#VM_Operations_Post_Interfaces_IOperationsAnimation_TopColor}

Gets or sets the color used at the upper part of the animation background.

```csharp
Color TopColor { get; set; }
```

### Property Value

 Color

### Remarks

`TopColor` and [`BottomColor`](/lib/VM-Operations-Post-Interfaces-IOperationsAnimation-BottomColor) define the upper and lower colors of the animation background. The selected colors are also used when animation frames are captured.
