## Close\(\) {#VM_Post_API_OutputReader_OutputReader_Close}

Closes [`OutputReader`](/lib/VM-Post-API-OutputReader-OutputReader).

```csharp
public void Close()
```

### Remarks

[`OutputReader`](/lib/VM-Post-API-OutputReader-OutputReader) has no method to open another result file afterward, so this call leaves the object permanently unusable. Construct a new [OutputReader\(string\)](/lib/VM-Post-API-OutputReader-OutputReader--ctor) to read a result file again.
