## Activate\(\) {#VM_Operations_Post_Interfaces_IPage_Activate}

Activates [`IPage`](/lib/VM-Operations-Post-Interfaces-IPage).

```csharp
void Activate()
```

### Examples

```python
page_name = "Page"
page = application_handler.GetPage(page_name)
page.Activate()
```

### Remarks

Activating `IPage` deactivates other pages, so one page remains active at a time.

After this call, [GetActivePage\(\)](/lib/VM-API-Post-Operations-ApplicationHandler-GetActivePage) reports this page.
