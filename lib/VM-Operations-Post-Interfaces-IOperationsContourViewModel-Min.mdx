## Min {#VM_Operations_Post_Interfaces_IOperationsContourViewModel_Min}

Gets or sets the lower contour range limit used when [`AutoRange`](/lib/VM-Operations-Post-Interfaces-IOperationsContourViewModel-AutoRange) is `false`.

```csharp
double Min { get; set; }
```

### Property Value

 double

### Remarks

Changing this value updates the scalar range only when manual range mode is active.
