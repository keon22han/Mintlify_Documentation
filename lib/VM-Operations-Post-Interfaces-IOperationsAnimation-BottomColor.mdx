## BottomColor {#VM_Operations_Post_Interfaces_IOperationsAnimation_BottomColor}

Gets or sets the color used at the lower part of the animation background.

```csharp
Color BottomColor { get; set; }
```

### Property Value

 Color

### Remarks

`BottomColor` and [`TopColor`](/lib/VM-Operations-Post-Interfaces-IOperationsAnimation-TopColor) define the lower and upper colors of the animation background. The selected colors are also used when animation frames are captured.
