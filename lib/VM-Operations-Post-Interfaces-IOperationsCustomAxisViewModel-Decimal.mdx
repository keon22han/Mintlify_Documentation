## Decimal {#VM_Operations_Post_Interfaces_IOperationsCustomAxisViewModel_Decimal}

Gets or sets the number of decimal places, from `0` through `16`, used in axis labels when manual decimal formatting is enabled.

```csharp
int Decimal { get; set; }
```

### Property Value

 int

### Remarks

Changing this value updates the axis text format together with [`LabelFormatType`](/lib/VM-Operations-Post-Interfaces-IOperationsCustomAxisViewModel-LabelFormatType).
