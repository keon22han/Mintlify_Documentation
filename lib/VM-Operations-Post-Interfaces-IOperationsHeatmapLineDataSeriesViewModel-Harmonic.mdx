## Harmonic {#VM_Operations_Post_Interfaces_IOperationsHeatmapLineDataSeriesViewModel_Harmonic}

Gets or sets the harmonic slope used at the beginning of the generated curve.

```csharp
double Harmonic { get; set; }
```

### Property Value

 double

### Remarks

Changing this value changes the harmonic slope used when the related heat-map curve is generated in a 3D STFT representation.
