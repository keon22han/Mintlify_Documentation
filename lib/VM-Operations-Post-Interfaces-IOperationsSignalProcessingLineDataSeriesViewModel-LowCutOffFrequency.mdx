## LowCutOffFrequency {#VM_Operations_Post_Interfaces_IOperationsSignalProcessingLineDataSeriesViewModel_LowCutOffFrequency}

Gets or sets the lower cutoff frequency, in the frequency unit of the source curve, for band-pass or band-stop filtering.

```csharp
double LowCutOffFrequency { get; set; }
```

### Property Value

 double

### Remarks

This value is used when [`FilteringType`](/lib/VM-Operations-Post-Interfaces-IOperationsSignalProcessingLineDataSeriesViewModel-FilteringType) selects a band filter. Changing it recalculates the calculated curve when an original curve exists.
