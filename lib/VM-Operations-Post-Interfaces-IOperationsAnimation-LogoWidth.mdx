## LogoWidth {#VM_Operations_Post_Interfaces_IOperationsAnimation_LogoWidth}

Gets or sets the logo width in pixels.

```csharp
uint LogoWidth { get; set; }
```

### Property Value

 uint

### Remarks

The value controls the logo width when [`IsVisibleLogo`](/lib/VM-Operations-Post-Interfaces-IOperationsAnimation-IsVisibleLogo) is `true`. The logo file is selected with [`LogoPath`](/lib/VM-Operations-Post-Interfaces-IOperationsAnimation-LogoPath).
