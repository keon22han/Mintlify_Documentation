## StateInfoPosition {#VM_Operations_Post_Interfaces_IOperationsAnimation_StateInfoPosition}

Gets or sets the state-information position selected from [`Layout`](/lib/VM-Models-Post-Layout).

```csharp
Layout StateInfoPosition { get; set; }
```

### Property Value

 [Layout](/lib/VM-Models-Post-Layout)

### Remarks

[`Layout`](/lib/VM-Models-Post-Layout) selects a predefined corner position for the overlay in the animation view and captured frames when [`IsVisibleStateInfo`](/lib/VM-Operations-Post-Interfaces-IOperationsAnimation-IsVisibleStateInfo) is `true`.
