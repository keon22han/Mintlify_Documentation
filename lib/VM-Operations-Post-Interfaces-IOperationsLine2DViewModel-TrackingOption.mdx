## TrackingOption {#VM_Operations_Post_Interfaces_IOperationsLine2DViewModel_TrackingOption}

Gets or sets [`ChartAxisType`](/lib/VM-Models-Post-ChartAxisType) mode used when tracking displays data points over the chart. `Single` tracks one curve and `Multiple` tracks several curves.

```csharp
ChartAxisType TrackingOption { get; set; }
```

### Property Value

 [ChartAxisType](/lib/VM-Models-Post-ChartAxisType)

### Remarks

When [`TrackingCurve`](/lib/VM-Operations-Post-Interfaces-IOperationsLine2DViewModel-TrackingCurve) is enabled, `Single` tracks the nearest curve and `Multiple` tracks all applicable curves at the hovered position.
