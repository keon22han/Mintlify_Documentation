## ShowAnimationBar {#VM_Operations_Post_Interfaces_IOperationsLine2DViewModel_ShowAnimationBar}

Gets or sets whether the animation bar is rendered for the 2D chart. `true` renders the bar and `false` hides it.

```csharp
bool ShowAnimationBar { get; set; }
```

### Property Value

 bool

### Remarks

Changing this value changes the chart's data-tracking controls.
