## NavigationCubePosition {#VM_Operations_Post_Interfaces_IOperationsAnimation_NavigationCubePosition}

Gets or sets the navigation-cube position selected from [`Layout`](/lib/VM-Models-Post-Layout).

```csharp
Layout NavigationCubePosition { get; set; }
```

### Property Value

 [Layout](/lib/VM-Models-Post-Layout)

### Remarks

[`Layout`](/lib/VM-Models-Post-Layout) selects a predefined corner position for the overlay in the animation view and captured frames when [`IsVisibleNavigationCube`](/lib/VM-Operations-Post-Interfaces-IOperationsAnimation-IsVisibleNavigationCube) is `true`.
