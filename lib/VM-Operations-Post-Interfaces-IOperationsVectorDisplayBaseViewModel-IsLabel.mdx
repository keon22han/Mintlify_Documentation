## IsLabel {#VM_Operations_Post_Interfaces_IOperationsVectorDisplayBaseViewModel_IsLabel}

Gets or sets whether the vector label is displayed. `true` shows the label and `false` hides it.

```csharp
bool IsLabel { get; set; }
```

### Property Value

 bool

### Remarks

The label background and text colors affect the rendered label when this value is `true`.
