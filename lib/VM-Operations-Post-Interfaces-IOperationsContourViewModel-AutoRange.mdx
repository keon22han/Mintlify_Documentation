## AutoRange {#VM_Operations_Post_Interfaces_IOperationsContourViewModel_AutoRange}

Gets or sets whether contour range limits are calculated automatically. `true` calculates them automatically and `false` uses [`Min`](/lib/VM-Operations-Post-Interfaces-IOperationsContourViewModel-Min) and [`Max`](/lib/VM-Operations-Post-Interfaces-IOperationsContourViewModel-Max).

```csharp
bool AutoRange { get; set; }
```

### Property Value

 bool

### Remarks

Changing this value updates contour rendering and enables manual [`Min`](/lib/VM-Operations-Post-Interfaces-IOperationsContourViewModel-Min) and [`Max`](/lib/VM-Operations-Post-Interfaces-IOperationsContourViewModel-Max) control only when it is `false`.
