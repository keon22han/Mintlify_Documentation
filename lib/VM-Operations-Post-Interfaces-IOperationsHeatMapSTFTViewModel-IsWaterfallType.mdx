## IsWaterfallType {#VM_Operations_Post_Interfaces_IOperationsHeatMapSTFTViewModel_IsWaterfallType}

Gets or sets whether the STFT view uses waterfall mode. `true` uses the waterfall view and `false` uses the 2D heat-map view.

```csharp
bool IsWaterfallType { get; set; }
```

### Property Value

 bool

### Remarks

Changing this value switches the active curve source between [`STFT2DViewModel`](/lib/VM-Operations-Post-Interfaces-IOperationsHeatMapSTFTViewModel-STFT2DViewModel) and [`STFT3DViewModel`](/lib/VM-Operations-Post-Interfaces-IOperationsHeatMapSTFTViewModel-STFT3DViewModel). The selected representation also supplies the active and selected curve collections.
