## ExportAllDataSeries\(\) {#VM_Operations_Post_Interfaces_IOperationsHeatMapBaseViewModel_ExportAllDataSeries}

Exports the heat-map view's own X, Y, and Z grid values.

The created file uses the same text table format as [ExportAllCurves\(string\)](/lib/VM-Operations-Post-Interfaces-IOperationsHeatMapBaseViewModel-ExportAllCurves).

```csharp
void ExportAllDataSeries()
```

### Examples

```python
heatmap.ExportAllDataSeries()
```

### Remarks

The operation opens a file-save dialog and exports the heat-map data to the selected location. Use `ExportAllCurves(string)` when the output path must be supplied programmatically.
