## LogoHeight {#VM_Operations_Post_Interfaces_IOperationsAnimation_LogoHeight}

Gets or sets the logo height in pixels.

```csharp
uint LogoHeight { get; set; }
```

### Property Value

 uint

### Remarks

The value controls the logo height when [`IsVisibleLogo`](/lib/VM-Operations-Post-Interfaces-IOperationsAnimation-IsVisibleLogo) is `true`. The logo file is selected with [`LogoPath`](/lib/VM-Operations-Post-Interfaces-IOperationsAnimation-LogoPath).
