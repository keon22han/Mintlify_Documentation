## LineStyle {#VM_Operations_Post_Interfaces_IOperationsLineDataSeriesViewModelBase_LineStyle}

```csharp
LineStyleType LineStyle { get; set; }
```

### Property Value

 [LineStyleType](/lib/VM-Models-Post-LineStyleType)

### Remarks
