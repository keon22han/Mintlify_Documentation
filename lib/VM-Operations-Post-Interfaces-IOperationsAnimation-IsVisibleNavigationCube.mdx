## IsVisibleNavigationCube {#VM_Operations_Post_Interfaces_IOperationsAnimation_IsVisibleNavigationCube}

Gets or sets whether the navigation cube is visible. `true` shows it and `false` hides it.

```csharp
bool IsVisibleNavigationCube { get; set; }
```

### Property Value

 bool

### Remarks

The navigation cube is drawn in the animation view and in captured animation frames when this value is `true`. Its position is controlled by [`NavigationCubePosition`](/lib/VM-Operations-Post-Interfaces-IOperationsAnimation-NavigationCubePosition).
