## LabelTextColor {#VM_Operations_Post_Interfaces_IOperationsCSYSViewModel_LabelTextColor}

Gets or sets the color used to render coordinate-system label text when [`IsVisibleLabel`](/lib/VM-Operations-Post-Interfaces-IOperationsCSYSViewModel-IsVisibleLabel) is `true`.

```csharp
Color LabelTextColor { get; set; }
```

### Property Value

 Color

### Remarks

This value has no visible effect while the coordinate-system label is hidden.
