## AddCurves\(string, PlotParameters\) {#VM_Operations_Post_Interfaces_IOperationsLine2DViewModelBase_AddCurves_System_String_VM_Models_OutputReader_PlotParameters_}

Adds curves to the chart by reading data from the specified file path and using [`PlotParameters`](/lib/VM-Models-OutputReader-PlotParameters). For details about preparing target values, see [Operation API Example - Creating Curves](/document/operation-api/example/example_chart_for_operation_api#creating-curves).

For a complete operations, see [Operation API Example - Creating Curves](/document/operation-api/example/example_chart_for_operation_api#creating-curves).

```csharp
IOperationsLineDataSeriesViewModelBase[] AddCurves(string filepath, PlotParameters parameters)
```

### Parameters

`filepath` string

The path to the file containing the curve data.

`parameters` [PlotParameters](/lib/VM-Models-OutputReader-PlotParameters)

Plot parameters defining the target entity, data paths, coordinate system, and data type used to add the curves.

### Returns

 [IOperationsLineDataSeriesViewModelBase](/lib/VM-Operations-Post-Interfaces-IOperationsLineDataSeriesViewModelBase)\[\]

An array containing the added [`IOperationsLineDataSeriesViewModelBase`](/lib/VM-Operations-Post-Interfaces-IOperationsLineDataSeriesViewModelBase) objects in the order created.

### Examples

```python
# Get the result document.
# RESULT_FILE_PATH : .dfr result file path
document = application_handler.GetDocument(RESULT_FILE_PATH)

# Create the chart view.
page = application_handler.GetActivePage()
chart_name = "Chart"
chart = page.CreateChart(chart_name)

# Add curves to the chart.
curve_paths = List[str]()
curve_path = "Displacement/Magnitude"
curve_paths.Add(curve_path)
entity_name = "Crank"
parameters = PlotParameters()
parameters.Paths = curve_paths
parameters.Target = entity_name
curves = chart.AddCurves(RESULT_FILE_PATH, parameters)
```

### Remarks

The method reads data from the specified file path and adds the resulting curves to the chart using the provided plot parameters. An empty array is returned when no curves are added.
