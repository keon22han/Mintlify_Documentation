## operator ==\(Point2D, Point2D\) {#VM_Point2D_op_Equality_VM_Point2D_VM_Point2D_}

Determines whether two [`Point2D`](/lib/VM-Point2D) values are equal by comparing their coordinates.

```csharp
public static bool operator ==(Point2D left, Point2D right)
```

### Parameters

`left` [Point2D](/lib/VM-Point2D)

The first value to compare.

`right` [Point2D](/lib/VM-Point2D)

The second value to compare.

### Returns

 bool

<a href="https://learn.microsoft.com/dotnet/csharp/language-reference/builtin-types/bool">true</a> if the two values have equal coordinates; otherwise, <a href="https://learn.microsoft.com/dotnet/csharp/language-reference/builtin-types/bool">false</a>.
