## MeanStressCorrection {#VM_Operations_Post_Interfaces_IOperationsFEBody_MeanStressCorrection}

Gets or sets the correction method selected from [`MeanStressCorrection`](/lib/VM-Models-Post-MeanStressCorrection) for stress-life fatigue analysis.

```csharp
MeanStressCorrection MeanStressCorrection { get; set; }
```

### Property Value

 [MeanStressCorrection](/lib/VM-Models-Post-MeanStressCorrection)

### Remarks

This property applies when [`AnalysisType`](/lib/VM-Operations-Post-Interfaces-IOperationsFEBody-AnalysisType) selects stress-life analysis. Changing it updates the mean-stress correction stored for fatigue evaluation.
