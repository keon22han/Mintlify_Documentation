---
title: "Overview"
---
The Operation API provides an in-process Python interface for automating operations in the running Ansys Motion Standalone Postprocessor. Its entry point exposes operations for loading result documents, organizing pages and views, configuring animation and chart data, and running supported analyses.

Use this API for operations that work with the active Postprocessor session, including its pages, views, documents, and operation interfaces.

For downloadable API modules, result files, and example scripts, see [Introduction](/index).

## Features

| Feature | What you can do |
|---|---|
| [Import File](/document/operation-api/feature/op_import_file) | Import result documents and add external numeric data to a chart. |
| [Manage Page](/document/operation-api/feature/op_manage_page) | Create, get, activate and close pages. |
| [Manage View](/document/operation-api/feature/op_manage_view) | Create, get, activate, close, and dock views within a page. |
| [Configure Camera Position](/document/operation-api/feature/op_configure_camera_position) | Set the camera viewpoint for an animation and prepare frame-specific camera specifications. |
| [Follow a Moving Target](/document/operation-api/feature/op_follow_moving_target) | Configure an animation camera to follow a selected target through the loaded frames. |
| [Manage a Coordinate System](/document/operation-api/feature/op_manage_coordinate_system) | Create, get, remove, and configure coordinate systems used by an animation. |
| [Control Animation Playback](/document/operation-api/feature/op_control_animation_playback) | Load, play, record, stop, and position animation frames. |
| [Manage a Contour](/document/operation-api/feature/op_manage_contour) | Create, get, remove, export and configure contour data in an animation. |
| [Manage a Vector](/document/operation-api/feature/op_manage_vector) | Create, get, remove, and configure vector display data in an animation. |
| [Animation Properties](/document/operation-api/feature/op_animation_properties) | Configure animation display and presentation properties. |
| [Manage a Curve](/document/operation-api/feature/op_manage_curve) | Create, get, remove, and export curves in a chart. |
| [Postprocess a Curve](/document/operation-api/feature/op_postprocess_curve) | Create calculated curves through mathematical and signal-processing operations. |
| [Curve Properties](/document/operation-api/feature/op_curve_properties) | Configure the properties of chart curves. |
| [Chart Properties](/document/operation-api/feature/op_chart_properties) | Configure chart appearance and display behavior. |
| [Manage Expression](/document/operation-api/feature/op_manage_expression) | Create, get, and remove expressions for a dynamic analysis result. |
| [Manage an Analysis Result](/document/operation-api/feature/op_manage_analysis_result) | Read contour and curve metadata, read result state, and create contours. |
| [Run an Analysis](/document/operation-api/feature/op_run_analysis) | Run fatigue and sound-pressure analysis operations. |
