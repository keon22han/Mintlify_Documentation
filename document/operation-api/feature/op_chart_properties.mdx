This feature covers setting how [`IOperationsLine2DViewModelBase`](/lib/VM-Operations-Post-Interfaces-IOperationsLine2DViewModelBase) looks and, with [`IOperationsLine2DViewModel`](/lib/VM-Operations-Post-Interfaces-IOperationsLine2DViewModel), what it shows. These settings change the chart itself, while its curve data stays ready for curve operations and export.

## Configuring
Set these properties to change the chart:

- Background and border color with [`Background`](/lib/VM-Operations-Post-Interfaces-IOperationsLine2DViewModelBase-Background) and [`BorderColor`](/lib/VM-Operations-Post-Interfaces-IOperationsLine2DViewModelBase-BorderColor).
- Title text with [`ChartTitle`](/lib/VM-Operations-Post-Interfaces-IOperationsLine2DViewModelBase-ChartTitle).
- Title color, face, size, style, and weight with [`FontColor`](/lib/VM-Operations-Post-Interfaces-IOperationsLine2DViewModelBase-FontColor), [`FontFace`](/lib/VM-Operations-Post-Interfaces-IOperationsLine2DViewModelBase-FontFace), [`FontSize`](/lib/VM-Operations-Post-Interfaces-IOperationsLine2DViewModelBase-FontSize), [`FontStyle`](/lib/VM-Operations-Post-Interfaces-IOperationsLine2DViewModelBase-FontStyle), and [`FontWeight`](/lib/VM-Operations-Post-Interfaces-IOperationsLine2DViewModelBase-FontWeight).
- Single-axis or multiple-axis display with [`ChartAxisType`](/lib/VM-Operations-Post-Interfaces-IOperationsLine2DViewModelBase-ChartAxisType).

## Displaying
For `IOperationsLine2DViewModel`, show or hide the X and Y axes with [`AxisX`](/lib/VM-Operations-Post-Interfaces-IOperationsLine2DViewModel-AxisX) and [`AxisY`](/lib/VM-Operations-Post-Interfaces-IOperationsLine2DViewModel-AxisY).

Show or hide the legend and the animation bar with [`ShowLegend`](/lib/VM-Operations-Post-Interfaces-IOperationsLine2DViewModel-ShowLegend) and [`ShowAnimationBar`](/lib/VM-Operations-Post-Interfaces-IOperationsLine2DViewModel-ShowAnimationBar).

- Show or hide minimum and maximum values with [`ShowVisibleMinMax`](/lib/VM-Operations-Post-Interfaces-IOperationsLine2DViewModel-ShowVisibleMinMax).
- Show or hide tracking with [`TrackingCurve`](/lib/VM-Operations-Post-Interfaces-IOperationsLine2DViewModel-TrackingCurve), and choose how tracking behaves with [`TrackingOption`](/lib/VM-Operations-Post-Interfaces-IOperationsLine2DViewModel-TrackingOption).

Set up the chart legend itself with [`Legend`](/lib/VM-Operations-Post-Interfaces-IOperationsChartViewModel-Legend).
