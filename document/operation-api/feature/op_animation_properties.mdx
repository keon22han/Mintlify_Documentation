This feature covers reading animation metadata and setting the visual parts of [`IOperationsAnimation`](/lib/VM-Operations-Post-Interfaces-IOperationsAnimation). These settings change the animation view, and the same change appears in frames captured through [Control Animation Playback](/document/operation-api/feature/op_control_animation_playback#recording).

## Reading Metadata
Read the analysis type with [`AnalysisResultType`](/lib/VM-Operations-Post-Interfaces-IOperationsAnimation-AnalysisResultType) and the source result file path with [`DocumentFilePath`](/lib/VM-Operations-Post-Interfaces-IOperationsAnimation-DocumentFilePath). The path identifies the result data behind the animation.

## Configuring the Background
Set the lower and upper background colors with [`BottomColor`](/lib/VM-Operations-Post-Interfaces-IOperationsAnimation-BottomColor) and [`TopColor`](/lib/VM-Operations-Post-Interfaces-IOperationsAnimation-TopColor).

## Configuring the Logo
Show or hide the logo with [`IsVisibleLogo`](/lib/VM-Operations-Post-Interfaces-IOperationsAnimation-IsVisibleLogo). Set its file, size, position, and transparency with [`LogoPath`](/lib/VM-Operations-Post-Interfaces-IOperationsAnimation-LogoPath), [`LogoHeight`](/lib/VM-Operations-Post-Interfaces-IOperationsAnimation-LogoHeight), [`LogoWidth`](/lib/VM-Operations-Post-Interfaces-IOperationsAnimation-LogoWidth), [`LogoPosition`](/lib/VM-Operations-Post-Interfaces-IOperationsAnimation-LogoPosition), and [`Opacity`](/lib/VM-Operations-Post-Interfaces-IOperationsAnimation-Opacity).

## Configuring the Navigation Cube
Show or hide the navigation cube with [`IsVisibleNavigationCube`](/lib/VM-Operations-Post-Interfaces-IOperationsAnimation-IsVisibleNavigationCube), and set where it sits with [`NavigationCubePosition`](/lib/VM-Operations-Post-Interfaces-IOperationsAnimation-NavigationCubePosition).

## Configuring State Information
Show or hide state information with [`IsVisibleStateInfo`](/lib/VM-Operations-Post-Interfaces-IOperationsAnimation-IsVisibleStateInfo). Set its position and text color with [`StateInfoPosition`](/lib/VM-Operations-Post-Interfaces-IOperationsAnimation-StateInfoPosition) and [`TextColorStateInfo`](/lib/VM-Operations-Post-Interfaces-IOperationsAnimation-TextColorStateInfo).
