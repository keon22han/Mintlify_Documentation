---
title: "Manage a Contour"
---
This feature covers finding valid targets, creating contour data for them, changing how the contour looks, and exporting the result. Once enabled, the contour is shown in [`IOperationsAnimation`](/lib/VM-Operations-Post-Interfaces-IOperationsAnimation) view and appears in any frames captured from that view, and its data can also be saved to a file. Creating, finding, and removing contour data use [`IOperationAnalysisResult`](/lib/VM-Operations-Post-Interfaces-IOperationAnalysisResult), its display settings use [`IOperationsContourViewModel`](/lib/VM-Operations-Post-Interfaces-IOperationsContourViewModel), and exporting uses [`Export`](/lib/VM-API-Post-Operations-Export).

## Creating
Create `IOperationsContourViewModel` with [`CreateContour(IList<string>, ContourMappingType, string, string, string)`](/lib/VM-Operations-Post-Interfaces-IOperationAnalysisResult-CreateContour). The new contour is added to the analysis result, so it can be turned on and shown in the animation.

Find target entity names that support a mapping type with [`GetContourables(ContourMappingType)`](/lib/VM-Operations-Post-Interfaces-IOperationAnalysisResult-GetContourables). For a selected target and mapping type, find available characteristics with [`GetContourCharacteristics(string, ContourMappingType)`](/lib/VM-Operations-Post-Interfaces-IOperationAnalysisResult-GetContourCharacteristics). Then find available components with [`GetContourComponents(string, ContourMappingType, string)`](/lib/VM-Operations-Post-Interfaces-IOperationAnalysisResult-GetContourComponents).

Pass the selected target names, mapping type, characteristic, and component to `CreateContour(IList<string>, ContourMappingType, string, string, string)`.

## Exporting
Export contour data with [`ExportContourResultToFile(string, string, IList<string>, bool, ContourMappingType, string, AnalysisResultType, FileFormatType)`](/lib/VM-API-Post-Operations-Export-ExportContourResultToFile).

<Danger>
The active view must be `IOperationsAnimation` for the chosen document, and an animation frame must already be loaded, before this export is called. Load a frame with the operations described in [Control Animation Playback](/document/operation-api/feature/op_control_animation_playback#loading).
</Danger>

## Properties
Change how the contour looks and behaves with these properties:

- Name it with [`FullName`](/lib/VM-Operations-Post-Interfaces-IOperationsContourViewModel-FullName).
- Pick its component, and check which ones are available, with [`Component`](/lib/VM-Operations-Post-Interfaces-IOperationsContourViewModel-Component) and [`ComponentList`](/lib/VM-Operations-Post-Interfaces-IOperationsContourViewModel-ComponentList).
- Turn it on or off with [`IsEnabled`](/lib/VM-Operations-Post-Interfaces-IOperationsContourViewModel-IsEnabled).
- Use an automatic range or set one by hand with [`AutoRange`](/lib/VM-Operations-Post-Interfaces-IOperationsContourViewModel-AutoRange), [`Min`](/lib/VM-Operations-Post-Interfaces-IOperationsContourViewModel-Min), and [`Max`](/lib/VM-Operations-Post-Interfaces-IOperationsContourViewModel-Max).
- Blend colors smoothly, or use a logarithmic scale, with [`Continuous`](/lib/VM-Operations-Post-Interfaces-IOperationsContourViewModel-Continuous) and [`LogScale`](/lib/VM-Operations-Post-Interfaces-IOperationsContourViewModel-LogScale).
- Choose which extreme values are shown with [`MinMaxTargetType`](/lib/VM-Operations-Post-Interfaces-IOperationsContourViewModel-MinMaxTargetType).
- Show or hide the legend, and set its color and text color, with [`LegendVisibility`](/lib/VM-Operations-Post-Interfaces-IOperationsContourViewModel-LegendVisibility), [`LegendColorScheme`](/lib/VM-Operations-Post-Interfaces-IOperationsContourViewModel-LegendColorScheme), and [`LegendFontColor`](/lib/VM-Operations-Post-Interfaces-IOperationsContourViewModel-LegendFontColor).
