This feature covers naming a curve and setting how its line, points, and curve form look with [`IOperationsLineDataSeriesViewModelBase`](/lib/VM-Operations-Post-Interfaces-IOperationsLineDataSeriesViewModelBase). These settings apply to a curve already added through [Manage a Curve](/document/operation-api/feature/op_manage_curve) or created through [Postprocess a Curve](/document/operation-api/feature/op_postprocess_curve), and change how that curve appears in the chart.

## Configuring
Name the curve with [`SeriesName`](/lib/VM-Operations-Post-Interfaces-IOperationsLineDataSeriesViewModelBase-SeriesName).

Set the line's thickness, color, and style with [`Thickness`](/lib/VM-Operations-Post-Interfaces-IOperationsLineDataSeriesViewModelBase-Thickness), [`Color`](/lib/VM-Operations-Post-Interfaces-IOperationsLineDataSeriesViewModelBase-Color), and [`LineStyle`](/lib/VM-Operations-Post-Interfaces-IOperationsLineDataSeriesViewModelBase-LineStyle).

Set the point size and point shape with [`PointSize`](/lib/VM-Operations-Post-Interfaces-IOperationsLineDataSeriesViewModelBase-PointSize) and [`PointType`](/lib/VM-Operations-Post-Interfaces-IOperationsLineDataSeriesViewModelBase-PointType).

Choose how the curve as a whole is drawn with [`SeriesType`](/lib/VM-Operations-Post-Interfaces-IOperationsLineDataSeriesViewModelBase-SeriesType).
